# YotaPaper v0.5

## 控制中心：两轮合并重构

### 第一轮：控制中心并入主页窗口
- 主页前台下拉时，控制中心改为在**主页同一窗口内**以浮层打开，与主页翻页动画共用同一机制（先 `EInkSdk.applyPageTurn` 武装、再切换可见性），开合连贯、无“新窗口首帧吞动画 / 动画延后”的问题。
- 其它应用前台时仍回退到独立窗口打开，保证任何界面都能唤出控制中心。
- 手势服务根据 LauncherActivity 是否在前台自动分发：主页 → 浮层（广播），其它应用 → 独立窗口。

### 第二轮：合并为单一共享核心
- 抽出 `ControlCenterUi` 作为唯一实现：按钮绑定、状态刷新、通知列表、媒体卡、授权流程等逻辑只保留一份（此前独立窗口与浮层互为复制，数百行重复代码易分叉）。
- `ControlCenterActivity`（兜底窗口）与 `ControlCenterPanel`（主页浮层）成为薄壳，只负责窗口形态、生命周期与动画决策。

## 动画规则
- 动画开关仅在主页浮层生效；其它应用前台的兜底窗口一律瞬时开合、不播动画。
- 修复收起时偶发“播两遍刷新才收干净”：收起前取消延迟补刷、隐藏后不再重建视图，每次开 / 合只产生一次干净的 EPD 更新。
- 下拉呼出手势起手区从屏幕顶部 25% 收紧到 **10%**（EPD 顶部 128px 内起手），更贴近状态栏下拉习惯。

## 最近任务清理（Root）
- 清理提速：运行中的应用最多 **3 路并发强停**，串行等待 ≈ 单批时间。
- 只对仍有进程的应用执行 root force-stop，空闲任务不再浪费强停。
- 修复“清理失效”：Android 5.0+ 的 `getRunningAppProcesses` 对三方应用只返回自身进程，会把其它应用全部误判为空闲而一个都不杀；改为 root `ps` 枚举进程（含 `pkg:子进程`），失败时自动退回全杀，旧行为不失效。

## 修复
- Android 4.x 低版本上 Launcher 顶部出现系统标题栏：主题父类改为 `Theme.DeviceDefault.Light.NoActionBar`。

# Yota Paper 使用说明

## 界面总览

- 底部三标签：**主页 / 应用 / 设置**；右下角为**锁屏**按钮。
- 顶部为时间与日期，左下角时间同时是“手动全刷”入口。
- 界面为白纸黑字 + 1px 灰线；无卡片、无系统弹窗式对话框（选择项使用底部弹窗列表）。

## 主页

- 默认 **4×3** 网格。
- 应用排序：**固定到主页的应用优先**，其余按 **点击次数** 从高到低排列。
- 单击图标：打开应用。
- 长按图标：弹出操作菜单（不淡化背景、无震动）：
  - 固定到主页 / 取消固定
  - 隐藏应用
  - 应用信息
- 双击底部「主页」标签：打开**最近任务**弹窗（见下）。
- 单击左下角时间：触发一次手动全刷，用于快速清除残影。
- 单击右上角「锁」：Yota 设备调用背屏 SDK 锁屏（无提示音）；非 Yota 设备回退为设备管理器锁屏。

## 应用抽屉

- 默认 **4×5** 网格。
- 左右或上下滑动均可翻页；页码显示在网格上方。
- 左上角「管理」进入批量模式：
  - 勾选应用后可**隐藏 / 显示 / 卸载**；
  - 点「完成」退出管理。
- 长按图标同样可固定、隐藏、查看应用信息。
- 应用安装 / 卸载 / 更新后列表自动刷新。

## 最近任务

- 打开方式：**双击底部「主页」标签**（或双击背屏 HOME）。
- 关闭方式：再次按 HOME、点击弹窗外的空白区域，或点「取消」。
- 默认只显示**最近 30 分钟**内使用过的应用；可在设置中调整时间范围：
  **关 / 5分钟 / 30分钟 / 1小时 / 6小时 / 1天**。
- 标题右侧「清空」：清空当前最近任务列表（清空后新使用的应用会重新进入列表）。
- 「取消」按钮的行为可在设置中选择：
  - 回到上一应用（默认）
  - 回到桌面

## 设置

设置页按分类折叠收纳：

| 分类 | 内容 |
|---|---|
| 网格与主页 | 应用列数/行数、应用分割线、主页列数/行数、主页分割线 |
| 图标 | 图标包、自动绘制线条图标 |
| 最近任务 | 仅显示近期使用（时间范围）、取消行为 |
| 刷新与动画（仅 Yota 设备） | 刷新模式、翻页动画、开屏动画、息屏动画 |
| EPD（仅 Yota 设备） | EPD 参数自动同步与应用、EPD 刷新参数管理 |
| 系统 | 使用说明、关于、恢复默认 |

- 点击分类标题行可展开/收起该分类。
- 多选项（列数/行数/时间范围/动画样式等）点击后在**底部弹窗列表**中选择，选中项以 **●** 标记。
- 「恢复默认」将全部设置恢复为默认值。

## 图标

- 默认开启**自动绘制线条图标**：根据应用原始图标生成黑色线条图标并缓存到本地。
- 可在设置中选择已安装的第三方图标包（支持 appfilter 映射）；未覆盖的应用回退系统图标。
- 切换图标包或线条图标开关时会自动清空/重建缓存。

## 状态信息

- 单击 **WiFi / 蓝牙** 文字直接开关；长按进入对应系统设置。
- 电量等信息实时刷新。

## WiFi 传书

- 单击顶部**时间**打开 WiFi 传书（需已连接 WiFi）。
- 手机在 **25025 端口**开启网页服务，电脑浏览器访问弹窗中显示的地址即可上传文件。
- 上传文件保存到内置存储的 `WIFI_transfer` 文件夹。

## 刷新与动画（仅 Yota 设备）

- 刷新模式：**高画质 / 流畅 / 自适应**。
- 动画跟随主模式：仅「高画质」模式显示并播放动画；「流畅 / 自适应」自动隐藏动画设置并使用快速刷新。
- 翻页动画：关闭 / 左右翻页 / 水平展开 / 水平闭合 / 上下翻页 / 垂直展开 / 垂直闭合。
- 开屏动画与息屏动画各有开关和样式；默认开屏为水平展开、息屏为水平闭合。
- 非 Yota 设备自动隐藏该分类，所有刷新与动画调用回退为普通绘制。

## 权限说明

| 权限 | 用途 |
|---|---|
| `PACKAGE_USAGE_STATS` | 最近任务列表（使用情况统计） |
| `QUERY_ALL_PACKAGES` | 枚举已安装应用 |
| `REQUEST_DELETE_PACKAGES` | 管理模式下卸载应用 |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | WiFi 状态开关 |
| `BLUETOOTH` / `BLUETOOTH_ADMIN` | 蓝牙状态开关 |
| `ACCESS_NETWORK_STATE` / `INTERNET` | WiFi 传书 |
| `KILL_BACKGROUND_PROCESSES` | 辅助进程清理（锁屏相关） |
| `WRITE_EXTERNAL_STORAGE`（仅 ≤28） | WiFi 传书写入文件 |
| `com.yotadevices.permission.ACCESS_BACK_SCREEN` | Yota 背屏 |
